# 오늘 뭐먹지? v39 — 단계형 점심 정산 UI

기존 v38 전체 기능과 API 파일 유지. 정산 화면만 점진적으로 펼쳐지는 5단계 UI로 개편했습니다.

1. 몇 명이서 먹었나요?
2. 어떻게 나눌까요? (똑같이 / 사람마다 다르게)
3. 얼마 나왔나요? (영수증 OCR, 메뉴별 배분, 동료 이름 선택 유지)
4. 커피도 마셨나요? (기존 커피 영수증, 메뉴별 배분, 사람 선택 유지)
5. 정산 결과 확인 (기존 정산 계산·복사·저장 로직 유지)

GitHub 루트의 index.html을 교체하면 됩니다. api 폴더는 기존 v38과 동일합니다.

주의: 실제 Vercel 배포와 OCR 및 모든 브라우저 시나리오의 종단간 테스트는 별도 필요합니다.

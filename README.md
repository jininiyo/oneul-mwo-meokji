# 오늘 뭐먹지? v51 — 도보 경로 및 혼밥 추천 개선

기준: v50 HTML(온보딩 이미지/룰렛/정산 기능 유지) + v44 API 폴더.

## 이번 수정
- 출발점: GPS/지도 핀 좌표를 그대로 TMAP 경로의 시작점으로 사용.
- 도착점: eat.pl 응답의 WGS84 좌표(coordX/coordY)가 유효하면 우선 사용. 없거나 다른 좌표계면 식당 주소를 좌표 변환. 실패 시 도보시간을 임의 생성하지 않음.
- 식당 목록 페이지당 10곳에 대해 최대 5개씩 나눠 도보 경로 조회. 다른 페이지 이동 시 그 페이지의 도보 경로 조회.
- TMAP 키 누락/식당 주소 좌표 변환 실패/경로 실패 안내 개선.
- 혼자 선택 시 혼밥 친화적인 메뉴 우선, 곱창/단체 메뉴 순위 하향. 실제 혼밥 가능 여부를 보증하지 않음.

## 배포
GitHub 저장소의 index.html 및 api/eatpl/walk.js 두 파일을 교체하세요. 기존 다른 API 파일은 그대로 유지하세요.
Vercel 환경변수 TMAP_APP_KEY 설정이 필요합니다. 환경변수 변경 후 재배포하세요.

## 검증 범위
HTML 인라인 JS 및 walk.js의 문법 검사 완료. 실제 Vercel 서버/외부 API 네트워크 요청은 실행 환경의 네트워크 제한으로 검증하지 못했습니다.
